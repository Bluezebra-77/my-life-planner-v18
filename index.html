Quick Actions

Use a special address to open the planner directly in Brain Inbox. You do not change anything in GitHub.

How do I use this on iPhone?
  1. Tap Copy address.
  2. Open the Shortcuts app and create a new shortcut.
  3. Add the action Open URLs and paste the copied address.
  4. Name the shortcut Brain Inbox. Siri can then run it by name.

You can also paste the copied address into Safari and bookmark it or add it to the Home Screen.

Five daily backups

One dated copy is kept for each of the latest five days. A safety copy is also made before data migration or restore.

Where can I find my backups?

Automatic daily backups: stored privately inside this browser on this device.

Visible backup files: choose Save backup file or Share backup, then save to iCloud Drive, OneDrive or Files.

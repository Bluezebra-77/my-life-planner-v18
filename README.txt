My Life Planner v38

Corrective release: Timeline rendering is isolated so it cannot stop dashboard and list summaries. Timeline now accepts current and legacy date/name fields and skips malformed records safely.


v38 changes: Lists navigation is side-mounted on larger screens and opens from a compact side tab on phones. List jumps now leave headings fully visible, and Save in the Custom List editor saves and closes the dialog.

v37 changes: Lists navigation moved to the top and the Planner header and progress area became more compact.

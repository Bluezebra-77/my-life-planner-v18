My Life Planner
Version 48
Date: 31 July 2026

RELEASE OBJECTIVE
Make the planner easier to use at the start of each day by providing fast capture for one-off daily intentions and a calmer, collapsible Home dashboard.

NEW
- Today's Focus: type a one-off job and press Return to add it immediately.
- Unfinished Today's Focus items automatically carry into the current day.
- Completed Focus items move below active items, are struck through and can be reinstated.
- Every main Home section can be collapsed or expanded; the chosen state is remembered.
- Project steps are collapsed by default in the Projects list and can be expanded per project.

FIXED / IMPROVED
- Lists search now includes appointment cards.
- Clearing Lists search restores all sections and respects saved project expansion states.
- A project is automatically expanded when a matching step is found by search.
- Completed Custom List items are struck through and sorted below active items; unticking reinstates them.
- The unclear header progress bar has been hidden pending a later redesign around meaningful daily progress.

PRESERVED
- Existing saved data and localStorage keys.
- Existing appointments, tasks, projects, custom lists, routines, Brain Inbox and settings.
- Existing v47 stability fixes.

DEFERRED
- Recurring tasks that stay overdue until completed (for example, a weekly injection).
- Smart List types, dates and reminders.
- Built-in task timer.
- Larger Home/Planner duplication review.

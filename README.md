# My Life Planner v51

My Life Planner is a calm, browser-based personal organiser designed around real-life use: capture first, organise later, and improve over time.

## Install or update

1. Upload every file in this package to the root of the GitHub Pages repository, replacing the previous app files.
2. Open the planner and choose **Settings -> App maintenance -> Check for updates**.
3. Confirm **v51** in the header, **Version 51** in About, and the **my-life-planner-v51** cache in Developer Dashboard.
4. Complete `TEST_CHECKLIST_v51.md` before accepting the release.

## Data safety

The app continues to use the established `lifePlannerData` browser-storage key. The v51 migration framework creates a safety backup before schema changes, validates migrated data, and supports rollback diagnostics. Today's Focus also retains its independent safety mirror.

## Main v51 capabilities

- Today's Focus quick capture, notes, pinning, ordering, timer and Convert workflow
- Recurring tasks that remain due until completed
- Advanced monthly recurrence such as second Thursday or last Friday
- Tags and forgiving list search
- Quick Add from anywhere
- Planner Health suggestions with snooze and dismiss memory
- Timeline, projects, cleaning, Waiting For, Brain Inbox and custom lists
- Editable Daily Rhythm and Gentle close-down routines
- Collapsible Home and Settings sections

See `USER_GUIDE.pdf` and `QUICK_START_GUIDE.pdf` for use instructions.

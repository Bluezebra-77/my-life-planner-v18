MY LIFE PLANNER — DESIGN NOTES

CORE PRINCIPLES
- The planner adapts to how the user lives.
- One item has one logical home; other screens are views.
- Real-world usage drives development.
- User-created information must survive upgrades.

MIGRATION FRAMEWORK
- Saved data carries schemaVersion 51.
- Migrations run in order and create a safety backup first.
- Migrated data is verified; failure restores the pre-migration snapshot.

ROUTINE DESIGN
- Daily Rhythm and Gentle close-down are user-owned lists, not hard-coded prescriptions.
- Defaults apply only when no saved list exists.
- Users can add, edit, remove and reorder items.
- Routine arrays remain in the authoritative lifePlannerData record.

HOME CONTROL DESIGN
- Panel action buttons and Show/Hide controls share a dedicated responsive control group.
- Collapse controls must never cover or obscure capture, manage or refresh actions.

MY LIFE PLANNER — DESIGN NOTES

CORE PRINCIPLES
- Capture first, organise later.
- One item has one logical home; Home provides useful working views.
- Existing user data is preserved through every release.

TODAY WORKSPACE
- Reordering must not require repetitive reopening.
- A running timer may be minimised but only an explicit cancel clears it.
- Timer state is restored from an absolute finish time after app suspension.

CONVERSION
- Converted items prefill the destination form.
- Recurrence and due dates must behave exactly like items created directly in that destination.


QUICK ADD
- Capture should be available without navigating away first.
- Quick Add launches the authoritative item editor; it does not create duplicate records.
- The floating control must not obscure bottom navigation or active timer controls.
